# 🌿 2D_HealingGame

Unity와 C#을 학습하며 개발하는  
**2D 탑다운 픽셀 힐링 / 생활 시뮬레이션 게임 프로젝트**입니다.

## 🎮 게임 소개

도시 생활에 지친 주인공이 시골의 낡은 집에 정착하여  
집을 직접 복구하고 새로운 생활을 만들어가는 게임입니다.

농사, 채집, 낚시 등을 통해 돈과 재료를 얻고  
집을 수리하거나 가구를 배치하고 확장할 수 있습니다.

마을의 NPC들과 친해지면 할인이나 정보 등의 혜택을 받을 수 있지만,
친밀도는 게임 진행에 필수가 되지 않도록 설계할 예정입니다.

---

## 🎯 개발 목표

- Unity 2D 기능 학습
- C# 코드 직접 작성 및 이해
- 확장 가능한 게임 시스템 구현
- 완성 가능한 규모의 2D 게임 제작
- 포트폴리오 프로젝트 완성

> 콘텐츠는 적게, 시스템은 제대로.
