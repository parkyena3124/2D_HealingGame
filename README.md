# 🌿 2D_HealingGame

Unity와 C#을 학습하며 개발하는  
**2D 탑다운 픽셀 힐링 / 생활 시뮬레이션 게임 프로젝트**입니다.

## 🎮 게임 소개

도시 생활에 지친 주인공이 시골의 낡은 집에 정착하여  
집을 직접 복구하고 새로운 생활을 만들어가는 게임입니다.

농사, 채집, 낚시 등을 통해 돈과 재료를 얻고  
집을 수리하거나 가구를 배치하고 확장할 수 있습니다.

마을의 NPC들과 친해지면 할인이나 정보 등의 혜택을 받을 수 있지만,
친밀도는 게임 진행에 필수가 되지 않도록 설계할 예정입니다.

---

## 🎯 개발 목표

- Unity 2D 기능 학습
- C# 코드 직접 작성 및 이해

- 완성 가능한 규모의 2D 게임 제작
- 포트폴리오 프로젝트 완성

> 콘텐츠는 적게, 시스템은 제대로.

## 📍 현재 진행 상황

**Phase 3 - 상호작용 시스템 진행 중 🔄**

Phase 2에서 Tilemap 기반 맵과 플레이어 이동,
충돌, 카메라 추적, Idle / Walk 애니메이션 및
이동 방향에 따른 Sprite 반전을 구현했습니다.

현재 Phase 3에서는 플레이어 주변에 `InteractionRange`를 만들고
Trigger를 이용해 상호작용 가능한 오브젝트의
범위 진입과 이탈을 감지하도록 구현했습니다.

`Interactable` Tag를 이용해 일반 벽이나 맵 오브젝트와
상호작용 가능한 오브젝트를 구분하고 있으며,
`RangeCheck` 스크립트에서 현재 범위 안의 상호작용 대상을
저장하고 관리하도록 구현했습니다.

E키 입력과 상호작용 대상 존재 여부를 확인하는 조건까지 작성했으며,
다음 개발에서 실제 상호작용 실행 테스트를 진행할 예정입니다.

최종 픽셀아트 캐릭터와 맵 그래픽은
주요 게임 시스템이 갖춰진 이후 제작 및 교체할 예정입니다.
